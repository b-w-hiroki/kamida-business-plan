# kamida-business-plan

## KAMIDA 仲介事業 収支計画ツール

KAMIDA 仲介販売事業の収支計画を立てるための、単一HTMLファイルで完結するブラウザツールです。ビルドやサーバーは不要で、変数を変更すると自動で再計算され、実績データはブラウザに自動保存されます。

## 開き方

`index.html` をブラウザで開き、「KAMIDA 事業計画ツール を開く」リンクから本体（`KAMIDA_事業計画ツール.html`）へ進みます。本体ファイルを直接開いても使えます。

## できること

- **変数設定**：販売単価・手数料率、計画開始月・初月の販売目標台数・月次成長率・計画期間、月額固定費（人件費、営業・交通費、マーケ・広告費、その他経費）、初期投資、実効税率、年間減価償却費を入力できます。
- **ダッシュボード／月次推移・実績入力**：月ごとの計画台数・計画収入・計画費用・計画利益に対して実績台数を入力すると、実績収入・達成率・差異・累積利益が計算されます（達成率 = 実績収入 ÷ 計画収入 × 100）。
- **年次P&L**：年度ごとに計画台数、手数料収入、固定費、営業利益、減価償却、法人税等、純利益、累積純利益を表示します（純利益 = 営業利益 − 減価償却費 − 法人税等。赤字時は課税なし。初年度のみ初期投資を固定費に加算）。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | 入口ページ（本体へのリンク） |
| `KAMIDA_事業計画ツール.html` | ツール本体 |

## 備考

- 実績データはブラウザ（localStorage）に保存されます。再度開いても保持されますが、ブラウザや端末を変えると引き継げません。
